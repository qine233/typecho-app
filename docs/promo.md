如果你也维护着自己的博客，大概有过这样的时刻：躺在床上突然想到一句该记下来的话，掏出手机打开后台——那个为电脑设计的、表格套着表单的界面，瞬间就把这点表达欲按回去了。或者在菜市场买完菜，一手袋子一手手机，还是没能把今天的菜钱记上。

NLecho 就是为这些时刻做的。它是给我自己的博客「团子笔记」写的原生 Android 客户端，Kotlin + Jetpack Compose，数据全部走 Typecho 自带的 XML-RPC 接口——**不用装任何服务端插件**，装了 Typecho 就能直连。

## 它长得不像个博客后台

第一眼的感觉应该是：这是个内容 App，不是管理工具。

首页是双列瀑布流，顶部一颗搜索药丸加一条分类横向筛选条；单独一个「日记动态」标签，把归在日记分类下的文章按日期倒序排成时间线，单列大图。详情页是笔记式的：多图轮播、正文懒加载、评论按父子关系还原成嵌套回复树，底部一条固定的赞 / 收藏 / 评论互动栏。

点进文章那一下我做了个较真的处理：**封面是「飞过去」的，不是换页**。列表卡片上的那张图和详情页首屏的大图是同一个共享元素，360ms 里一起长大、一起挪位，正文淡入淡出。列表滑到哪儿、点开的是哪一格，眼睛跟得住。长按卡片还会就地弹出一张预览——标题、摘要、分类、评论数，点它就等于打开原文，点外面收起，不用在列表和详情之间来回横跳。

界面整体是暖棕强调色配灰底白卡，深色模式跟随系统，字体缩放全局生效（连正文渲染区一起跟着变）。顶部和底部各有一条玻璃：底部胶囊是真的透，卡片滚过时能看见颜色在玻璃下面化开；顶栏则通栏贴住屏幕、压成磨砂，只在一条发丝分隔线处把内容隐进模糊里。

## 写作是真的能在手机上完成

这是我最在意的部分，因为大部分「博客 App」只给个输入框。

- **Markdown 正文 + 实时预览**，三种排布随手切：只写、上下分屏（上写下看，边打字下面跟着长出来）、只看渲染结果。预览停手 220ms 才渲，而且渲在后台线程，长文不卡输入框。
- **撤销 / 重做**、全屏沉浸写作、分类与标签、存草稿。
- **插图能排顺序**：正文里有图片时，编辑器下方排出一列带序号角标的缩略图，长按拖到想要的位置就当场改写那段 Markdown——只搬那张图自己那一行，不留空行也不粘连，而且这一步算进撤销历史，拖错了按一次撤销就回去。
- **发布时间可控**：新建默认此刻，编辑老文章默认沿用原文时间，改一篇旧文不会把它顶到最新。
- **自动存稿**：输入停顿即落盘，进程被杀或闪退后重进会问一句要不要恢复。
- **图片上传**：相册选图 → 本地压缩 → 上传 → 正文内联。配了 Cloudreve 图床就拿永久直链，没配则走 Typecho 自己的附件接口。

发布之后 App 会把站点回传的编号认回本篇，接着改就是原地编辑，不会出现「同一篇发两遍」。

管理员账号登录后会多出「管理」标签：文章列表（发布/草稿/私密状态切换、删除）、评论审核（通过 / 垃圾 / 删除 / 回复）、页面管理，还有一个我被迫做出来的**重复文章清理**——整站一页页翻完，标题+正文归一后完全相同的算一组，每组自动留最早那篇，多出来的默认勾上一次删掉。

## 顺手把生活记录也塞进来了

博客这种东西，记的从来不只是文章。

装了配套的 NolineApi 插件（可选，不装其余功能照旧），「健康」标签就有体重和体脂率的按天记录：当前值、BMI、目标进度、7/30/90 天变化和趋势折线图。同一个开关下面还有**买菜记账**——本月大额与涨跌、本周/本年/累计、近 7 个月柱状、分类占比、最近流水；点任意月份出**月度报告**，合计、开火天数、日均、单笔均值、最贵那几笔一次算全。预算能设总额和八个分类额度，超了就把进度条画满并在通知里写明「本月买菜超预算 x 元」。

断网也不影响记录：先进本机队列，恢复后自动补交。桌面还有一颗 3×3 的小组件，本月合计、今天花了几块、预算进度和待同步笔数一眼看到，底下三个品名是最近买过的——点一下就直接进录入面板，**品名和分类已经替你填好了**。

配了 Cloudreve 还能在「管理 → 网盘」里浏览目录、上传下载、建文件夹、重命名、移动，给任意文件生成永久直链或带提取码的分享。

## 一些看不见的地方

- **冷启动先出内容**：文章列表持久化缓存，不等网络就先把首页画出来，再静默刷新。
- **常驻状态通知**：写清还有多少条记录没交到站点、上次补交是什么时候、这个月哪几类超了预算，通知上带「立即补交」。后台补交走 WorkManager 周期任务，进程被杀排期还在，不喜欢也可以整个关掉。
- **数据与存储**：安装包 / 图片缓存 / 更新包 / 文章缓存 / 待同步记录 / 本地草稿按实际占用分类列成占比条，缓存可单类清理——草稿和待同步队列只报数、给逐条删除和立即补交，**永远不进「清理缓存」**，不会被顺手清掉。
- **应用内检测更新**：问 GitHub Releases 要最新版，下载可选镜像站加速，下完对 sha256 校验，渠道不对绝不硬装。
- **252 个单元测试**，协议细节全部对着 Typecho 源码核过——Typecho 的 XML-RPC 和 WordPress 并不完全一致，这些不一致都处理好了。

## 谁能用

任何装了 Typecho 的站点。填三项就行：站点地址、XML-RPC 路径（默认 `/action/xmlrpc`）、你的 Typecho 账号。Android 8.0 以上可装。

界面是按「一个博主 + 一台手机」做的，所以它偏私人：瀑布流的分类判定、日记时间线这些逻辑都假设站主是一个人写。想给多人博客用，可能得动一点适配。

**下载**：[GitHub Releases](https://github.com/qine233/typecho-app/releases/latest) 有 CI 打好的安装包，仓库里也能自己编译。代码在 [qine233/typecho-app](https://github.com/qine233/typecho-app)。

博客不该是只有开着电脑才能维护的东西。想一想，掏出手机，两下就记完——这才是它该有的样子。
